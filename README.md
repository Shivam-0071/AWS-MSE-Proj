LearnHub – E-Learning Website <br>
<br>
A simple e-learning platform built using **HTML, CSS, and JavaScript** that allows users to explore courses, track learning progress, and test their knowledge through quizzes.<br>
<br>
Features-<br>
- Browse and search available courses.<br>
- View course details and lessons.<br>
- Track completed lessons and learning progress.<br>
- Take timed multiple-choice quizzes.<br>
- Get instant feedback on quiz answers.<br>
- View quiz scores on a leaderboard.<br>
<br>
Available Courses<br>
- HTML Basics<br>
- CSS Basics<br>
- JavaScript Basics<br>
